# VarshaMitra — Hyperlocal Climate Risk Prediction & Decision Support

**PCCOE Indradhanu International Grand Challenge 2026 · AI for Climate Action**

VarshaMitra is a frontend hackathon prototype that turns climate and weather
signals into hyperlocal agricultural decisions. It answers one question for a
farmer: *what should I do next?*

> **This is a prototype.** Every forecast, risk score and advisory in this
> application is simulated demo data generated by a deterministic mock model
> (see [`MOCK_DATA.md`](./MOCK_DATA.md)). Nothing here is a live IMD forecast.

## Three killer features

1. **Hyperlocal monsoon intelligence** — 7/14/30-day onset, dry-spell and
   heavy-rain probabilities with a stated confidence level.
2. **Hyperlocal climate risk map** — state → district → block drill-down with
   a plain-language "why is this area at risk?" explanation.
3. **Crop-specific actionable advisory** — location + crop + crop stage →
   one recommendation, with the reasoning shown alongside it.

## Getting started

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run start    # serve the production build
```

No environment variables or backend are required — the app is entirely
frontend + local mock data.

## Tech stack

- **Next.js 16** (App Router) + **TypeScript**
- **Tailwind CSS v4** for styling
- **MapLibre GL** for the client-side risk map
- **Recharts** for rainfall, temperature and historical charts
- **lucide-react** for icons
- **Python 3.12 + FastAPI** (under `backend/`) for climate indicators, soil intelligence, and agronomic advisory services

## Project structure

See [`ARCHITECTURE.md`](./ARCHITECTURE.md) and [`backend/README.md`](./backend/README.md) for full breakdowns. In short:

```
backend/          Python FastAPI service (services, indicators, agronomy, tests)
src/
  app/            Next.js routes (public, /farmer/*, /officer/*)
  components/     Shared UI primitives & modularized shell
  features/       Feature-scoped components (risk-map, advisory helpers, charts)
  data/           Local mock datasets + deterministic fallback logic
  i18n/           English + Marathi dictionaries and language context
  hooks/          App-wide client state (role, location, crop)
  lib/api/        Typed API client connecting frontend to FastAPI backend
  types/          Shared TypeScript types
tests/            Frontend API client & live integration test suites
```

## Language support

The entire interface — including navigation, dashboards, the map, and every
generated advisory — is available in **English** and **Marathi**, switchable
from the language control in the top navigation. See
[`UI_UX_GUIDELINES.md`](./UI_UX_GUIDELINES.md) for how translations are wired.

## Honesty by design

VarshaMitra is built to complement official sources like IMD, not replace
them. Every screen that shows a probability or risk score is labelled as
prototype/simulated output, and no accuracy metric is claimed anywhere in the
product because no model has been trained yet.
